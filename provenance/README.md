# Registration document provenance

The files here preserve the study’s registration documents and amendments as recorded in its source history. `registration-history.json` records their source commit identifiers, author/committer dates, and SHA-256 hashes. The code and result snapshot used for this release is source commit `2c5c6581204ad9dfbc5b2cc4136bc50abb1809d5`.

Source commit identifiers describe the study’s development history and may not resolve in this repository, which contains a release snapshot. Git metadata alone is not an independent public timestamp or registry certification. These files preserve the record that exists; they do not create a retrospective public preregistration.
