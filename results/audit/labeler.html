How to label (click to hide)
  • Read the conversation top to bottom, like a person would.
  • Uses the number from: which earlier answers does this question compute with? If that earlier number were wrong, this answer would be wrong too. Click those turns, or None.
  • Wording points back to: does the question say "it", "this", "that", "the same", or leave out the subject, so you need an earlier question to know what it means, without using its number? Click the turn(s) you would need to read to understand the question (not a turn that merely asked the same thing before), or None. Test: could you answer it correctly from the question and the report alone, without reading the earlier question? If yes, None (a conversational "what about..." on a fully stated question is None).
  • The test for "uses": if only that earlier turn's answer were wrong (every other earlier answer shown correctly), would this answer change? Only then click it. This is what the experiment does: it corrupts one answer at a time. A turn that matters only through another turn's result is not clicked (GS turn 4 uses turn 2's change, not turn 0). A number that was an ingredient in an earlier turn's calculation and is read again from the report does not count (e.g. 448,859 is an input to turn 0's total, but turn 1 reads it from the table, so turn 1 uses = None).
  • Asking for a number again ("what was the 2016 value?") is a fresh lookup: uses = None.
  • If the same number was answered twice before, click both turns.
  • Reading programs: every program is written from scratch and never mentions earlier turns, even when the question uses them (turn 2 recomputes the total instead of "taking turn 0"). So a program not mentioning a turn proves nothing. #0, #1 mean "step 0, 1 of this program", not turn 0, 1. Decide from the question first, then use the program to check numbers.
  • If a turn is already clicked under uses, it is greyed out under points back to; click None there unless the wording points to a different turn.
  • Only count turns the question really needs. The programs sometimes repeat earlier steps that the question does not use.
  • If an earlier number is used only through another turn's result, click just that turn.
